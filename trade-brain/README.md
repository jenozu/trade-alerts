# Trade Brain

This directory is a version-controlled, Obsidian-compatible Markdown knowledge vault for the trading system.

It is designed to preserve strategy knowledge, architecture, decisions, research experiments, backtest evidence, data-source notes, project state, and references in a linked structure.

Use `[[wikilinks]]` between notes where useful. Keep raw/generated research artifacts outside Git when they are large; store durable conclusions, paths, hashes, metrics, and decisions here.

Start at [[Home]]. See [[SCHEMA]] for note rules and evidence standards.
